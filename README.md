კეთილი იყოს თქვენი მობრძანება Git & GitHub-ის პრაქტიკულ მოედანზე!

ეს რეპოზიტორია შექმნილია სპეციალურად თქვენთვის, რათა პრაქტიკაში გამოსცადოთ გუნდური მუშაობის, ვერსიების კონტროლისა და GitHub-ის ძირითადი ხელსაწყოები.

დავალების მიზნები (Checklist)

ამ სავარჯიშოს წარმატებით დასასრულებლად, თქვენ უნდა შეასრულოთ შემდეგი ნაბიჯები:

- [ ] **ნაბიჯი 0:** დააჭირეთ **"Star"** ღილაკს ამ გვერდის ზედა მარჯვენა კუთხეში (ამით გამოხატავთ მხარდაჭერას).
- [ ] **ნაბიჯი 1:** შექმენით ახალი **Issue** (პრობლემა/საკითხი).
- [ ] **ნაბიჯი 2:** გააკეთეთ ამ რეპოზიტორიის **Fork** და ჩამოტვირთეთ (**Clone**) თქვენს კომპიუტერში.
- [ ] **ნაბიჯი 3:** შექმენით ახალი ბრენჩი (**Branch**).
- [ ] **ნაბიჯი 4:** შეიტანეთ ცვლილება კოდში/ტექსტში და გააკეთეთ **Commit** & **Push**.
- [ ] **ნაბიჯი 5:** გამოაგზავნეთ ფულ რექვესთი (**Pull Request**).
- [ ] **ნაბიჯი 6:** დაუტოვეთ კომენტარი თანაკურსელის Pull Request-ს.

დეტალური ინსტრუქცია ნაბიჯ-ნაბიჯ:

### 1. Issue-ს შექმნა და დისკუსია
1. გადადით ამ რეპოზიტორიის **"Issues"** ტაბზე.
2. დააჭირეთ **"New Issue"**.
3. სათაურში დაწერეთ თქვენი სახელი და გვარი
4. აღწერაში დასვით რაიმე კითხვა Git-ის შესახებ ან უბრალოდ დაწერეთ "მზად ვარ!". დააჭირეთ **Submit**.

### 2. რეპოზიტორიის Fork და Clone
1. მთავარ გვერდზე დააჭირეთ **"Fork"** ღილაკს (ზედა მარჯვენა მხარეს), რათა ეს პროექტი თქვენს პირად ექაუნთზე გადაკოპირდეს.
2. თქვენი Fork-ირებული რეპოზიტორიიდან დააკოპირეთ URL ლინკი.
3. გახსენით ტერმინალი და ჩაწერეთ:
--bash
   git clone <თქვენი-ფორკირებული-რეპოს-ლინკი>
   cd <საქაღალდის-სახელი>

ახალი ბრენჩი:
git checkout -b feature/თქვენი-სახელი

ცვლილების შეტანა (კოდი ან ტექსტი)
გახსენით პროექტი თქვენს ედიტორში (მაგ: VS Code).
იპოვეთ საქაღალდე students/ (თუ არ არის, შექმენით).
შექმენით ახალი ფაილი თქვენი სახელით
შიგნით დაწერეთ მოკლე ინფორმაცია თქვენზე (მაგალითად: რა არის თქვენი მიზანი პროგრამირებაში).
შეინახეთ ფაილი და ტერმინალში გაუშვით:
git add .
   git commit -m "feat: added student profile"
   git push origin feature/თქვენი-სახელი

Pull Request (PR) გამოგზავნა:
დაბრუნდით ჩემს (ორიგინალ) GitHub რეპოზიტორიაზე.
ზედა ნაწილში დაინახავთ ყვითელ ზოლს და ღილაკს "Compare & pull request". დააჭირეთ მას.
აღწერაში მოკლედ დაწერეთ, რა ცვლილება შეიტანეთ და დათაგეთ თქვენ მიერ პირველ ნაბიჯზე შექმნილი Issue (მაგალითად: Closes #1).
დააჭირეთ "Create pull request".
